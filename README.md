# One Word, One Username, One Reward — make.fun entry

An entry for the make.fun competition **One Word, One Username, One Reward**.

`main.ts` (Node 22, stdlib only) writes the entrant's own make.fun username —
one word and nothing else — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program
validates that the text is a single bare token within the 30-character cap
before writing, and produces byte-identical output on every run.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The entry is the username itself, exactly as registered on make.fun — no
explanation, no links, no pitch, as the bounty demands.
